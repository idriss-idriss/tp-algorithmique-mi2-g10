# Exercice 9 : Pair ou impair

## Énoncé
Un entier est pair s'il est divisible par 2.
1. Écrire un algorithme qui lit un entier et indique s'il est pair ou impair.
2. Écrire ensuite une fonction F1(x) qui renvoie le reste de la division de x
   par 2, et l'utiliser dans l'algorithme.

## Solution
- **Principe :** si le reste de la division par 2 vaut 0, le nombre est pair,
  sinon il est impair.
- **Fonction :** `F1(x) = x%2`
