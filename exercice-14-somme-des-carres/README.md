# Exercice 14 : Somme des carrés

## Énoncé
1. Écrire un algorithme qui lit un entier n et affiche la somme
   1² + 2² + ... + n².
2. Écrire ensuite une fonction F1(x) qui renvoie le carré de x, et l'utiliser
   dans l'algorithme.

## Solution
- **Principe :** une boucle `POUR` de 1 à n qui ajoute le carré de chaque
  nombre à une variable `somme` (initialisée à 0).
- **Fonction :** `F1(x) = pow(x,2)`
