## 👋 À propos

Ce dépôt contient la résolution de mes exercices de TP du cours d'**Algorithmique**.
Chaque exercice est traité en deux étapes : d'abord l'algorithme complet,
ensuite la version utilisant la fonction `F1(x)`.

​```

- un `README.md` avec l'énoncé et l'explication de la solution ;
- `partie1.alg` : l'algorithme sans fonction ;
- `partie2.alg` : l'algorithme avec la fonction `F1(x)`.

## ▶️ Comment tester un algorithme

1. Télécharge et installe [AlgoBox](https://www.xm1math.net/algobox/) (gratuit).
2. Télécharge le fichier `.alg` de l'exercice voulu.
3. Dans AlgoBox : **Fichier → Ouvrir un algorithme**.
4. Clique sur **Lancer l'algorithme** et entre une valeur de test.
